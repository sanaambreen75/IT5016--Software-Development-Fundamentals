Library Management System
Description

This is a simple Library Management System written in Python using Object-Oriented Programming (OOP).

The program allows a library to manage books and members. It can add books, register members, borrow books, return books, and display the availability of books.

Features
Add books to the library
Add members to the library
Borrow books
Return books
Check whether a book is available or borrowed
Display book titles, authors, and availability
Classes

The program uses three main classes:

Book
Stores information about each book, including:
Book title
Author
Availability status

Member
Stores information about each library member, including:
Member name
List of borrowed books

Library
Manages the books and members in the library. It contains functions for:
Adding books
Adding members
Borrowing books
Returning books
Displaying all books
Example

The program adds two books:

Harry Potter by J.K. Rowling
The Hobbit by J.R.R. Tolkien

It also adds a member called Sana. The program then demonstrates borrowing and returning the book Harry Potter.

                    CAR CLASS EXAMPLE
A class is a blueprint, and an object is an instance of that blueprint. The __init__ method acts as a constructor to initialize object attributes. 
Description

This is a simple Python program that demonstrates the basics of Object-Oriented Programming (OOP) using a Car class.

The program creates car objects with a brand and model, then uses an instance method to display information about each car.

Features
Creates a Car class
Uses a constructor (__init__) to set car details
Uses instance attributes for the car brand and model
Uses an instance method to display car information
Creates multiple car objects
Example

The program creates two car objects:

Tesla Model 3
Ford Mustang
Example Output
This is a Tesla Model 3.
This is a Ford Mustang.
