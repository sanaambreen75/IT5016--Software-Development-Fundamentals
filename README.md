Library Management System
Description

This is a simple Library Management System written in Python using Object-Oriented Programming (OOP).

The program allows a library to manage books and members. It can add books, register members, borrow books, return books, and display the availability of books.

Features
Add books to the library
Add members to the library
Borrow books
Return books
Check whether a book is available or borrowed
Display book titles, authors, and availability
Classes

The program uses three main classes:

Book

Stores information about each book, including:

Book title
Author
Availability status
Member

Stores information about each library member, including:

Member name
List of borrowed books
Library

Manages the books and members in the library. It contains functions for:

Adding books
Adding members
Borrowing books
Returning books
Displaying all books
Example

The program creates two books:

Harry Potter by J.K. Rowling
The Hobbit by J.R.R. Tolkien

It also creates a member called Sana. The program then demonstrates borrowing and returning the book Harry Potter.

How to Run
Make sure Python is installed on your computer.
Open the project in VS Code.
Run the Python file using:
python library.py
